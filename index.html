Panduan Instalasi APK di HP Android

Ikuti panduan mudah berikut untuk mengunduh dan memasang aplikasi Mapdroid tanpa melalui Google Play Store.

1

Unduh Berkas APK

Klik tombol "Unduh mapdroid.apk" di halaman ini atau scan QR code untuk memulai unduhan berkas APK rilis terbaru.

2

Buka Berkas Unduhan

Setelah proses unduh selesai, buka panel notifikasi HP Anda atau buka folder Download di aplikasi File Manager Anda.

3

Izinkan Sumber Tidak Dikenal

Jika Android menampilkan peringatan keamanan, pilih Pengaturan lalu aktifkan opsi "Izinkan dari sumber ini" (Install Unknown Apps).

4

Pasang & Buka Aplikasi

Tekan tombol "Install", tunggu pemasangan selesai, lalu buka aplikasi Mapdroid dan izinkan akses lokasi (GPS).

Catatan Keamanan Android

File APK ini dibangun secara otomatis dan transparan melalui pipeline CI/CD GitHub Actions resmi repositori kami. APK aman dan bersih dari kode berbahaya. Jika Google Play Protect memberikan peringatan peringatan verifikasi, Anda dapat memilih "Install anyway".

Kelebihan Utama

Fitur & Arsitektur Mapdroid

Dirancang khusus untuk performa tinggi dengan teknologi peta vektor terkini.

MapLibre Native SDK

Rendering peta berbasis vektor yang mulus, cepat, dan tajam di berbagai resolusi layar HP dengan konsumsi kuota data minimal.

Pin & Koordinat Interaktif

Cukup ketuk lokasi mana saja di peta untuk menaruh penanda (marker) dan melihat koordinat Lintang (Latitude) dan Bujur (Longitude) secara presisi.

Multi-Style Layer Peta

Bebas berpindah gaya tampilan peta dengan satu sentuhan: MapLibre Demo, OpenFreeMap Bright, Liberty, hingga Positron minimalis.

Pelacak Lokasi GPS

Tombol "Lokasi Saya" untuk langsung mengarahkan kamera ke lokasi GPS Anda secara real-time lengkap dengan kompas dan akurasi.

100% Bebas Biaya API

Tidak memerlukan credit card atau API key berbayar seperti Google Maps atau Mapbox proprietary. Sepenuhnya mandiri dan gratis.

CI/CD Auto Release

Setiap perubahan kode yang di-push ke GitHub otomatis di-build oleh GitHub Actions, dibuatkan tag rilis, dan diunggah APK-nya.

Tampilan Aplikasi

Antarmuka Modern & Intuitif
